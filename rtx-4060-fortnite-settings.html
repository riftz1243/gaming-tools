Fortnite · GeForce RTX 4060

Best RTX 4060 settings for Fortnite.

Two practical starting points for Fortnite on the RTX 4060: one focused on competitive performance and another focused on stronger visual quality.

COMPETITIVE / HIGH FPS

Competitive Fortnite settings

Use this profile if your priority is responsiveness, visibility and high frame rates rather than visual effects.

Window Mode Fullscreen
Resolution Native resolution
Rendering Mode Performance Mode / DX12 Low
View Distance Medium / Far
Shadows Off
Textures Low / Medium
Effects Low
Post Processing Low
Motion Blur Off
V-Sync Off
Ray Tracing Off
NVIDIA Reflex On + Boost if available
Competitive tip: Keep your native resolution if possible and lower visual effects first. This usually preserves a clearer image while reducing unnecessary GPU load.
QUALITY / BALANCED

Higher quality Fortnite settings

Use this profile if you want better image quality while keeping the RTX 4060 workload reasonable.

Window Mode Fullscreen
Resolution 1080p or 1440p
Rendering Mode DirectX 12
View Distance Far
Shadows Medium
Textures High
Effects Medium
Post Processing Medium
Motion Blur Off
Upscaling DLSS Quality if needed
Ray Tracing Off
Frame Generation Optional if supported
Quality tip: Keep textures high and reduce shadows, effects and heavier lighting features first if performance drops.

Performance Mode or DirectX 12?

Performance Mode is the better fit when your main goal is high responsiveness and competitive play.

DirectX 12 is the stronger starting point if you care more about image quality and modern rendering features.

What should you lower first?

For competitive play, shadows, effects and post processing are sensible settings to keep low.

For a higher-quality setup, reduce shadows and effects before texture quality. This usually keeps the game looking sharp while cutting heavier GPU work.

About these recommendations

These settings are practical starting points rather than guaranteed FPS benchmarks.

Actual Fortnite performance can change with game updates, CPU performance, map areas, drivers and background applications.
