Which settings should you lower first?

Global illumination, shadows and reflections are good places to start if you need more performance. They can be more demanding than texture quality.

Keeping textures high usually gives a strong visual benefit, especially if VRAM usage remains under control.

Should you use Frame Generation?

Frame Generation can make the game look much smoother when supported, especially at higher resolutions.

It works best when your base frame rate already feels responsive. If the game feels sluggish before Frame Generation is enabled, lowering heavy graphics settings first is usually the better move.

Important: performance varies

These settings are recommended starting points rather than verified benchmark guarantees.

Actual performance can vary with your CPU, RAM, drivers, game updates, cooling and background applications.
